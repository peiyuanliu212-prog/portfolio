《乱世拼将》· 三国题材 H5 策略游戏

项目负责人：产品设计 / 数值体系 / 内容质量 / 测试验收
  • 主导设计完整游戏体系：90 位历史人物、6 大阵营、20 章闯关、20 种结局、17 项成就与人物图鉴系统，负责规则、数值平衡与百分制评分标准，产品持续迭代至 v5.10。
  • 统筹全部 AI 生成内容（人物文案、90 张人物头像、章节插图、剧情文本）的生产与审校，以历史常识为底线逐项核查，拦截史实与数值错误进入成品。
  • 建立严格验收流程：按真实操作路径逐项复测、逐个手算关键数值，不采信开发方自报结果。
  • 初版已通过虎扑平台审核正式上线；完整版同步发布于 GitHub Pages、腾讯云 EdgeOne 与 indienova。

《大金撤离》· 搜刮撤离类 H5 游戏

项目负责人：设计 / 数值模拟 / 质量把控
  • 自建蒙特卡洛数值模拟器（每组 5 万局、多配置多策略对照），完成概率体系、经济系统与评级标准的定量校准；在模拟与实测对照中发现并修复模拟器与游戏本体的多处隐蔽缺陷。
  • 组织多款大模型参与方案论证并担任最终裁决：期间逐项回查原始数据，识破并纠正协作模型虚构的多项统计结论，形成成文的「数据权威」规范——只认原始数据文件，不认任何一方的转述。
  • 产品已部署上线，含 40 件物品图鉴、6 大收藏套装与 13 项成就系统、三档难度仓库。

工作方法

对模型输出保持核查习惯：任何关键数字都要回到原始数据或实测结果验证；验收以真实操作路径为准，不采信自报结论；专业内容以事实底线为准入标准。这套方法同样适用于大模型评测、出题与数据审校工作。
